# Dash to 30 Audio Assets

File default saat ini:

- dt30-ui.wav: dipakai untuk semua interaction sound sementara.
- dt30-win.wav: dipakai saat player menang.
- dt30-lose.wav: dipakai saat player kalah/bankrupt.
- dt30-home-loop.wav: music halaman home.
- dt30-game-loop.wav: music in-game.

Untuk mengganti sound, replace file di folder ini atau ubah mapping di:

lib/audio/audioAssets.ts
